# Skill Template

## Purpose

Describe what this skill helps the agent do.

## When To Use

List the triggers that should activate the skill.

## Always Do

- Add concrete required behaviors.

## Never Do

## Workflow

1. Gather context.
2. Identify constraints.
3. Produce the artifact.
4. Verify against the checklist.
5. Revise if verification fails.

## Quality Checklist

- The output follows the user's goal.
- The workflow is executable.
- The instructions are specific.
- Edge cases are handled.
- Failure criteria are explicit.

## Examples

Include short examples that prevent common mistakes.

## Tests

Define tasks that should pass if the skill works.

## Failure Criteria

The skill fails if it produces generic advice, contradicts itself, ignores constraints, or cannot be evaluated.
